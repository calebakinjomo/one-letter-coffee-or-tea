An entry for [make.fun's "One Letter: Coffee or Tea" bounty](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

## The entry

Exactly one letter: **A** — coffee.

Coffee is the more vivid, funnier, truer choice: the deadlines, the debugging
fuel, the third cup before noon. No word, no explanation, no punctuation —
just the letter.

## How it works

`main.py` (Python 3, standard library only) writes the single character `A`
to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline.

## Run it

```sh
mkdir -p out
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out python3 main.py
# out/entry.txt contains exactly one character: A
```
